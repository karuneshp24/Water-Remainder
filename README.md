# 🌌 AQUA-G | Antigravity Hydration Tracker

[![FastAPI](https://img.shields.io/badge/Backend-FastAPI-009688.svg?style=for-the-badge&logo=fastapi&logoColor=white)](https://fastapi.tiangolo.com)
[![Glassmorphism](https://img.shields.io/badge/UI-Glassmorphism-06B6D4.svg?style=for-the-badge)](https://developer.mozilla.org/en-US/docs/Web/CSS/backdrop-filter)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

A premium, immersive web application that simulates a futuristic water reminder dashboard operating in a zero-gravity space environment. Features floating water droplets, glassmorphic UI cards, real-time countdown reminders, and an interactive hydration progress ring.

🪐 **Live Demo**: [https://water-remainder.onrender.com](https://water-remainder.onrender.com)

---

## ✨ Features

- 🌌 **Zero-G Environment Simulation**: Dreamy deep-space background with animated mesh gradients and floating procedural water droplets.
- 📱 **Levitating Phone Interface**: A central device frame mimicking a floating smartphone with glassmorphism layers (`backdrop-filter`) and realistic physics-like animations.
- 🌀 **Interactive Progress Ring**: A glowing, SVG-based circular progress tracker that dynamically pulses and updates as you log water.
- ⏱️ **Active Countdown Reminders**: Real-time timer indicating the exact minute and second of your next reminder.
- 🚨 **Holographic System Alerts**: Glowing notifications that pop up to synchronize hydration logs, plus critical red-glowing alerts when it's time to drink.
- 📲 **Mobile Sync QR Code**: Integrated QR card on the dashboard to easily scan and run the app on your mobile device.

---

## 🛠️ Technology Stack

- **Backend**: Python 3.x, [FastAPI](https://fastapi.tiangolo.com/) (High-performance API framework)
- **Frontend**: Vanilla HTML5, Custom CSS3 (with Glassmorphism & Keyframe Animations), Vanilla JavaScript
- **Server/Deployment**: [Uvicorn](https://www.uvicorn.org/), ready for [Render](https://render.com/) or [Railway](https://railway.app/)
